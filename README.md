# SAVAŞ — Arena Fighter

A lightweight browser fighting game designed for phones and desktop browsers. It uses HTML, CSS, and Canvas—no Android Studio or build step is needed to play.

## Play

Open the repository's GitHub Pages website (after enabling Pages in **Settings → Pages**, deploy from the `main` branch and `/` folder).

## Controls

- **Phone:** use the on-screen arrows, jump, kick, and punch buttons.
- **Keyboard:** A / D to move, W to jump, J to punch, K to kick.
- Select **RESTART** to play another round.

## Features

- Player versus CPU opponent
- Health bars and 60-second rounds
- Touch controls for mobile
- Installable web-app manifest and basic offline caching

## Project status

This is an early playable prototype. It is a browser game, not a native Android APK. The next development steps are improved combat, selectable fighters, levels, and sound.
